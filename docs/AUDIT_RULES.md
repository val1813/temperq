# 审计规则登记表

注册表版本：`audit_rules_v2`。本文件由 `qwb.audit_rules.document()` 生成，请勿手改；改规则时改代码并重新生成，测试会核对两者一致。

每条审计结论都标注它用到的规则编号。三类规则分开：规则事实不可调；有出处的方法写明来源；经验阈值是项目自己的判断，尚未经样本检验，可在审计设置的“判断口径”里调整，报告保存当次使用的值。

## 规则事实

| 编号 | 内容 | 来源 |
| --- | --- | --- |
| F-ACCOUNT | 权益 = 现金 + 持仓市值；持仓变化 = 成交；现金变化 = 成交金额 + 费用 | 账务恒等式 |
| F-TICK-STOCK | 股票最小报价单位 0.01 元 | 沪深交易所交易规则 |

## 有出处的方法

| 编号 | 内容 | 来源 |
| --- | --- | --- |
| M-TICK-HALF | 固定原成交、按每边半个最小价位计算价差压力情景；不认证实盘成本下限 | 作者 STRUCT 稿（SSRN，未经同行评审）；适用边界见 audit_research.tick_analysis |
| M-FIFO | 按先进先出配对买卖，计算每笔已平仓交易的持有期和盈亏 | 通用会计配对方法 |
| M-SLIPPAGE | 回测已计的滑点按平台文档换算为每边成本，价差情景只补差额 | 聚宽 set_slippage 文档；RQAlpha 滑点模型文档 |
| M-RANK-IC | 每个调仓日，用全部候选标的的分数与到下一调仓日的收益做秩相关（Spearman IC） | 因子检验常用方法（信息系数） |
| M-PREMISE-HAC | 前提检验的主 t 值 = IC 序列均值 / Newey-West（Bartlett 核）标准误；滞后期数 L = floor(4(n/100)^(2/9))，至少 1，按信号期计；期数少于 max(30, 4(L+1)) 不给 t；同时报告 L/2、L、2L；普通 t 只作诊断 | Newey & West (1987, Econometrica)；滞后规则为常用经验式，非最优选择 |
| M-PREMISE-POWER | 最小可检测 IC = (显著性 t 门槛 + 0.84) × IC 标准差 / √期数，0.84 对应八成检验力 | 统计检验力的正态近似（单侧） |
| M-RANK-REPLAY | 用策略导出的每日排名回放换仓次数；不重算收益 | 本项目，见 audit_signals |
| M-FILL-TIMING | 固定原成交股数和费用，把成交价换成同日其他分钟的收盘价，比较盈亏；不重跑策略决策 | 本项目，见 audit_timing |
| M-FILL-RANGE | 把每笔成交价放进当天最高最低价区间，和均匀分布比较；买在低位、卖在高位的比例显著超过随机即可疑 | 本项目，见 audit_fill_quality |
| M-FILL-FLOOR | 每笔买入按成交后 10 分钟内的最高价、卖出按最低价重算，股数费用不变；是执行的悲观下限，不是估计 | 本项目，见 audit_fill_quality |
| M-SEQUENCE | 从期初或上一收盘现金滚入当日更早成交及费用，判断同分钟回款依赖；缺成交时间或现金到账时刻的日期不判定。信号按完整日期、时区及时间比较，缺失或冲突记录不判通过 | 本项目，见 audit_sequence |
| M-CAPITAL-FLOOR | 在整手、预算约束下求目标权重的最小 L1 偏离（混合整数规划），忽略费用、T+1、量限和路径，是乐观下界 | 整数规划，本项目见 audit_capital |
| M-FULFILMENT | 逐标的逐日盈亏按前一日收盘是否持有、是否在当日目标内分组；收盘持仓按次日开盘价计隔夜盈亏 | 会计分组，本项目见 audit_fulfilment |
| M-MARKET | 日收益对平台基准日收益做最小二乘回归，得 β、年化超额及其 t 值；按日对数收益看最好 1% 的日子的贡献 | CAPM 回归；本项目见 audit_market |
| M-LIMIT-LOCK | 全天只有一个价格且等于涨停（跌停）价的封板日，买入（卖出）成交记为可能拿不到 | A 股涨跌停制度；本项目见 audit_limits |
| M-SPEC | 只检查用户在 strategy_spec 里声明的承诺；卖出失败、买单没买够等市场原因造成的偏离单列不计 | 本项目，见 audit_spec |
| M-DSR | 按声明的尝试次数计算 Deflated Sharpe：挑最好一个时纯靠运气可达的夏普门槛，以及校正后夏普大于零的概率 | Bailey 与 López de Prado（2014） |
| M-LISTINGS | 打分或成交早于上市日、晚于退市日即记为用了未来名单；股票候选池回测期内无一退市时提示可能的幸存者偏差 | 本项目，见 audit_listings |
| M-DECISIONS | 成交与策略自记的每日选择对照；同日换仓按委托编号判断买卖提交顺序；T+0 品种是否从不当天卖出；打分对下一期与再下一期收益的 IC 对比 | 本项目，见 audit_decisions |
| M-STATE | 策略自记的每日持仓与账户收盘持仓逐日比较，不一致即记为状态失配 | 本项目，见 audit_state |
| M-ACTIVITY | 卖单没成交完且收盘仍持有，记为退出未完成；收盘无任何持仓的交易日记为空仓，统计最长连续空仓 | 本项目，见 audit_activity |
| M-PARTIAL-ENTRY | 按委托记录的下单数和成交数找部分成交的买单，跟踪到该标的下一次委托或成交为止 | 本项目，见 audit_completion |
| M-GRID-PAIR | 独立起跑格与参考窗口同日期的连续切片配对：连续切片收益 = 末日权益 / 配对首日前一日权益 − 1；分信号与选择、组合目标、指令、执行结局、账户五层各自比较，各报第一次观测到的差异；目标只取决策记录，不由实际持仓反推 | 本项目，见 audit_grid 与 docs/STRATEGY_AUDIT.md；SPEC TEMPERQ_CLAIM_GRID_OFFLINE_SPEC_v1 §7 |

## 证据等级

| 等级 | 含义 |
| --- | --- |
| E1 | 记录事实：导出记录与账务恒等式上的复算 |
| E2 | 描述：事后分组，不证明改了会更好 |
| E3 | 情景：固定原成交，在声明假设下估计 |
| E3c | 条件情景：有前提未确认，结论随它变 |
| E4 | 同区间复跑：同一段历史重跑的比较，仍是样本内 |
| E5 | 独立验证段通过：冻结候选后在未看过的验证段通过 |
| E6 | 前向观察：模拟盘或实盘记录 |
| N | 待补材料：缺少计算所需材料 |
