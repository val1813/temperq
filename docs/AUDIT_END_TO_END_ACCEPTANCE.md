# 审计版高级证据端到端验收

基础验收检查上传、确认、一键审计、金额报告及下载。高级证据另由
`scripts/check_audit_evidence_browser.py` 在已迁移的审计安装包上实际运行三组浏览器流程：

- 执行证据：合成订单差异被检出；母订单部分成交的实现短缺245元、机会成本80元；原始文件逐字节下载。
- 日终账户和因子：合成账目匹配、注入差异被检出；给定因子主动收益分解为−3.05%，缺暴露时不生成完整归因。
- 风险：已知方差；未来因子和留出冲击不改变截止时点预测；缺训练不预测、缺留出不伪造校准；零主动风险、未来权重拒绝、日历缺口拒绝、跨策略访问拒绝。

三组均检查桌面1440及手机390/320宽度、浏览器错误、原始资料下载和材料范围声明。执行器启动新的合成工作区，使用随包解释器；阻断外网和训练/取数模块，不写已有安装包或用户账户。当前仓库与全部随包Python模块须逐一同哈希。测试脚本可来自后续仅修改验收脚本的提交；报告分别记录运行包提交和验收脚本提交，不将二者混成同一版本。

```powershell
python scripts/check_audit_evidence_browser.py --app <迁移目录>/TemperQ --validation-fixture <显式合成账户测试材料> --risk-fixture <显式合成风险测试材料> --output <全新输出目录>
```

测试材料必须提供`fixture.json`及文件哈希。账户材料声明`validation_fixture_v1`，风险材料声明`risk_synthetic_browser_fixture_v1`，来源必须为`synthetic_fixture`；浏览器脚本再次核对声明与哈希。已有合成验收材料可只读复用，不计作新独立盲测或券商证据。

本轮用户已排除真实券商对账：本地没有独立券商材料，该层未验证。软件端到端通过不建立机构准入；真实执行校准、独立未见标签验证、连续前向观察和独立复核仍需各自证据。不可将合成注入检查改称已完成实盘验证。
