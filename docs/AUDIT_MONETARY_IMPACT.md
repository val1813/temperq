# 问题涉及多少钱

金额是对材料中历史路径的分配或明示假设下的情景，不是修复收益预测。账目必须 verified 才进入金额层。每个金额在 evidence.json 的 modules.monetary_impact 中保留分类、范围、覆盖数、排除原因和明细；impact-money.csv 供逐项复算。现金缓冲与未补买单共享来源时只列一次金额，另一卡引用；不同问题仍可能涉及同一笔盈亏，禁止跨卡相加。

## 三类金额

- historical：实际回测路径上的净盈亏，含期末未实现盯市收益。它只是关联金额，不能解释为错误的因果损失或可追回收益。
- cost_scenario：保持成交不变的费用、价差或价格压力情景。成本暴露、费用差和可避免上限分别说明，均不称为确定节省。
- counterfactual：未买入股数乘起止收盘价之差，正数少赚，负数少亏。未计资金占用、补单成交限制、费用和后续信号变化。

## 归属约定

失败卖单：在失败日收盘标记 min(未成交数量, 实际持仓)；从下一交易日起，对标记股数按收盘价盯市，实际卖出优先消耗这些股数，按股数摊分卖出费用。重复失败委托不叠加同一股数，新增买入不计入原标记批次。不含失败日盈亏和原买入费；没有委托时点估值，不将当天较早收益算成退出失败的结果。公司行动证券暂不做该批次分配，逐标的原会计贡献仍保留。

封板/上市期外成交：复用原 FIFO 持仓模块的 entry_ref/exit_ref，只取关联成交真正匹配的批次，全持有期净盈亏含已平仓和期末估值。同一批次两端均异常只计一次；不混入同证券其他批次。不虚构未知期初成本，有公司行动或数量异常的批次沿用原模块排除。封板成交可能真实成交，因此该金额不能全称为实盘拿不到的钱。

状态不一致：按完整记录关联到不一致日及标的，提取该证券整日会计贡献；包括决策前盈亏，不冒称从错误发生后产生的损失。目标外持仓直接复用 fulfilment 的 outside 会计分组。价格异常显示导出估值下关联日贡献，不能解释为可信经济收益。决策卡金额仅覆盖买入违背当日选择的部分。

未补买单：部分成交沿用 completion 的观察窗；零成交到下一次委托、成交或明确落选之前/期末。只用返回的同口径收盘价；观察窗有公司行动或价格缺失时列为未覆盖；同标的观察窗重叠时排除后续段，避免重复假设仓位。该情景从下单日收盘起计，不假造当时可成交价格。

空仓：显示空仓日账户实际净盈亏，不以基准涨幅假造机会损失。没有目标、数量或可成交价格的其他检查仍列缺项，不填零。

## 改版比较与需要多少年

compare 要求账目闭合、相同期初资金、相同完整日期集合、同费用情景、无外部出入金、正权益路径。逐日配对差额为两版在同一费用/价差情景下的净盈亏之差，单位为元/日、同初始资金；不是复利收益率差。

均值标准误采用 Newey–West Bartlett HAC：带宽 floor(4(n/100)^(2/9))，长程方差采用 n/(n−1) 修正；给出 Student-t(n−1) 近似95%均值区间及更长带宽敏感性。少于252个配对交易日不展示观测差额年化；达到252日的年化区间也不是未来单年收益预测区间。少于30日不推断；零方差不声称未来确定。验证段单独估计。历史金额差本身已确定，区间描述的是假设平稳重复抽样下的平均差额不确定性。

条件规划总年数约为 (z(.975)+z(.8))² × 长程方差 / 目标日效应² / 252，双侧5%、80%检验力。目标效应必须预设，默认每年初始资金的2%，CLI用 `--minimum-effect-pct 2` 指定，网页也可修改；不根据观测均值反推效应。少于60个配对交易日不展示所需年数。报告尚无改版时，以每年初始资金2%及原策略波动作粗略规划示例，明确实际应使用改版配对差额波动。没有承诺未来会显著，也不把总样本量当还需追加年数。多次试改、选版本和非平稳风险不在此近似校正中，需冻结独立验证。

执行/量限实验用 `qwb audit compare 原版目录 改版目录 --sensitivity --json`。相同非空策略代码也会自动按敏感性处理。它仍能输出历史差额与日均区间，但不输出 signal、改善判断、观测年化或改善所需年数，不能据此选出更真实的撮合模型。

## 成交价压力情景

仅纳入核账区间内、成交后完整10个分钟都有有效高低价的成交，排除本分钟、重复分钟、缺失窗口及收盘截断。买单变化为（原成交价−窗口最高价）×数量，卖单变化为（窗口最低价−原成交价）×数量；负数表示情景少赚或多亏。覆盖率以核账区间成交额计。逐笔明细和排除原因在 fill-quality.csv，金额与明细求和一致。

这是每笔独立取极端价格、固定数量费用的情景，不重放订单、资金约束、盘口排队或后续信号。未覆盖成交沿用原价；金额可超过原净利润，不能称为实盘必然损失或回测必然多赚。
