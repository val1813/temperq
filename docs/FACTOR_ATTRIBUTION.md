# 时点行业／风格暴露与收益分解

`audit factor-attribution` 在来源明确声明的因子模型下，用区间期初权重和当时可得暴露计算行业／风格暴露、给定因子收益贡献及残差。组合、基准和主动部分分别列示，多期按复利链接。这是确定性的事后收益分解；没有估计因子收益、风险协方差、特异风险、VaR或风险预算，也不把残差称为策略alpha。

另有独立的[固定截止时点风险估计与留出诊断](RISK_MODEL_VALIDATION.md)，估计给定模型的因子／残差联合协方差及模型VaR/ES并评价留出收益；没有把本页事后归因结果自动转成已校准风险模型。

## 命令

```powershell
.venv\Scripts\qwb audit factor-attribution --scope <scope.json> --periods <periods.csv> --weights <weights.csv> --exposures <exposures.csv> --factor-returns <factor_returns.csv> --source-kind historical_data --out <全新报告.json> --json
```

五份输入必须分别提供。读取文件不会执行策略或改写账户。输出独占创建，不覆盖旧结果；省略 `--out` 时只打印JSON。退出码0为给定材料的完整分解已计算，1为材料不足，2为格式/口径错误或已有输出。除CLI外，策略导入页“账户、归因与风险证据”可保存这五份独立材料并复算，详见 [网页独立证据](VALIDATION_EVIDENCE.md)；未自动并入回测审计报告或计划流程，报告覆盖表仍明确列缺失输入。

单文件最多8MB，单CSV最多十万行，归因最多5000个区间；字段最多128字，source_ref最多1024字，因子definition最多4096字。数字采用普通十进制，最多10位整数及12位小数，拒绝NaN、Infinity、科学计数法和未知列。

来源必须主动选择 `historical_data`、`synthetic_fixture` 或 `historical_returns_synthetic_exposures`。最后一种专门声明真实收益混用合成暴露，不能当历史风险模型校准。所有类型均保留 source_authenticated=false。接口只核对声明，不证明文件源自独立机构。

## 区间与因子定义

scope JSON 的完整示例见 [合成范围](../examples/factor_attribution_synthetic/scope.json)，必填：

| 字段 | 含义 |
| --- | --- |
| schema_version | `factor_attribution_scope_v1` |
| start_time / end_time | 带时区的完整归因范围，起点严格早于终点 |
| holdings_complete | 必须是JSON布尔值true，声明每期双方完整权重 |
| cash_return | 固定 `zero`，表示现金的因子模型收益为零；实际现金利息仍在残差中 |
| max_exposure_age_days | 0至366整数，按暴露观测时点计算允许年龄，修订发布时间不会刷新观测年龄 |
| factors | 1至50个因子，每个有唯一name、industry/style类型、非空definition及固定unit `return_per_unit_exposure` |

definition 应写明行业分类版本、层级、总收益/价格收益、复权/分红、风格标准化、行业中性化、估计样本及因子收益构造方法。unit 表示一单位证券因子暴露对应的区间因子收益；不能把百分数、bp或不同标准化版本混入同列。仅填写非空定义不代表模型可识别或已经校准。相关或重叠的因子、重复解释同一收益等问题仍需外部模型复核。

`periods.csv`：

```csv
period_id,start_time,end_time,portfolio_return,benchmark_return,source_ref
p1,2025-01-02T15:00:00+08:00,2025-01-03T15:00:00+08:00,0.02,0.01,synthetic-nav-1
p2,2025-01-03T15:00:00+08:00,2025-01-06T15:00:00+08:00,-0.01,0.03,synthetic-nav-2
```

示例全部为合成。收益是同区间的**简单收益率小数**，0.02表示2%；不接受“2%”或bp数值。区间连续、不重叠，覆盖scope起止；周五至周一可以是一个明确区间，但不得删除一个中间区间后把余下日收益强接。接口不从区间恢复未提供的日历。收益须大于−1且不超过100；暂不处理净值归零后的收益、空范围、多币种及现金流调整方法。提交的观察收益应已经按一致的资金流、费用和净值口径核定。source_ref 指向原始记录，不填密钥。

## 期初权重与可得时间

`weights.csv` 表头：

```csv
period_id,book,code,weight,asof_time,available_at,source_ref
```

book 为 portfolio 或 benchmark，每区间两者都须有。每个证券一条，权重非负且不超过1；每组含现金行 `code=CASH`，即使现金权重为零也须显式列出。所有权重和为1，最多接受1e−12的表示误差，不自动归一化。当前只支持只做多的完整权重账本。

asof_time 必须等于对应区间start_time，available_at也须等于该时点；这是“期初状态在该时点已知”的严格接口。期末持仓不能改日期后回填成期初持仓，未来才发布的权重不能用于此入口。若实际链路在期初后才可得，不能伪造时间使其通过；应重新定义与实际信息可得时点一致的区间及收益，或保留为不具备本接口材料。程序不认证这些时间声明。

`exposures.csv` 表头：

```csv
code,factor,asof_time,available_at,exposure,source_ref
```

asof_time 是暴露所代表状态的观测时间；available_at 是该版本真正可得时间，必须不早于观测。每个证券／因子可有多个观测时点和多个修订版本，同一观测与发布时间的重复记录直接拒绝。

每个区间只选 `available_at ≤ start_time` 的版本，再优先选择最新观测时点，同一观测选最新已发布修订。晚发布的旧观测修订不能覆盖已经可得的更新观测。改未来数据不会改变此前归因。年龄按 `start_time − asof_time` 衡量；超过scope预算就标stale，不向前无期限填充。

正权重的每个非现金证券须显式提供所有声明因子的暴露；零暴露也须有记录，不把缺失当零。行业暴露在0至1之间，同证券全部行业暴露和为1；可采用有证据的ETF穿透份额，不能从ETF名称推造。风格暴露允许−1000至1000，定义中的标准化单位须一致。现金的因子暴露固定为零，不在exposures提供CASH记录。

## 因子收益与单期闭合

`factor_returns.csv` 表头：

```csv
period_id,factor,return,available_at,source_ref
```

每区间每因子必须有且仅有一条完整区间收益，允许−100至100的有符号值（风格因子可能是多空组合）。available_at不得早于区间end_time，这是事后归因材料，不能在期初作为已知收益使用。它的源数据和构造仍需核对；接口不能认证档案更新时间、因子独立性或构造模型。

期初证券权重为w，证券对因子f的暴露为x，因子收益为F：

- 组合因子暴露 `B_f = Σ_i w_i × x_if`。
- 单因子收益贡献 `C_f = B_f × F_f`。
- 观察收益 `R = Σ_f C_f + 残差`。
- 单期主动贡献为组合贡献减基准贡献，主动残差同理。

两边分别计算，不用主动权重替代完整双方权重。残差可能包含未建模风险、盘中交易、选择、费用、现金利息和估值差，不是自动识别的alpha或市场冲击。输出保留选中的具体暴露版本、source_ref、非现金权重覆盖率、缺失列表和逐项贡献；缺任意正权重证券的任一因子或区间因子收益时，该期不输出完整贡献，整体也不输出完整多期归因。已知的部分暴露仅用于定位缺口，不能当成完整组合暴露。

## 多期贡献

每日主动收益直接相加通常不等于两个净值累计收益之差。本入口使用后缀链接：对某一book，区间t的贡献乘以后续各区间实际收益的增长因子 `∏_(u>t)(1 + R_u)`；各因子贡献及残差分别累加，闭合到 `∏_t(1 + R_t) − 1`。

组合和基准使用**各自**的后缀乘数，最后相减为主动累计贡献。结果解释的是两个累计收益之差，不是组合净值／基准净值之比。输出保留link_multiplier和closure_error。闭合是一项恒等分解的数值核对，不证明因子模型解释正确。

## 样例与验收

[合成材料目录](../examples/factor_attribution_synthetic/scope.json) 有完整五份文件。组合期初A/B/现金权重0.6/0.2/0.2，基准0.5/0.5/0；两个行业和一个风格因子有明确合成暴露与收益。两期组合实际收益2%、−1%，基准1%、3%：

| 已知答案 | 数值 |
| --- | --- |
| 第一期组合因子模型收益／残差 | 1.5%／0.5% |
| 第二期组合因子模型收益／残差 | −1.4%／0.4% |
| 组合累计收益 | 0.98% |
| 基准累计收益 | 4.03% |
| 主动累计差 | −3.05个百分点 |
| 链接后的组合残差贡献 | 0.895个百分点 |
| 链接后的基准残差贡献 | 1.7275个百分点 |

`scripts/verify_factor_attribution.py --output <全新目录>` 经实际CLI验证已知答案、晚发布修订、未来修订不影响此前、缺暴露不足、未来权重拒绝、缺区间拒绝六类结果，保存输入与日志。单元验证另覆盖旧观测晚修订、过期、全现金、重复身份、单位/时区、行业份额及输出不覆盖。

本轮对E盘缓存做只读表头核查：存在daily_basic指标、历史index_members以及stock_basic缓存，但这些已核查材料没有可验证的行业／风格暴露版本与available_at。缓存抓取时间、历史成分生效日期和实际发布时间是不同概念，不能互相替代；因此没有把当前分类或财务字段直接填成历史因子暴露，没有宣称真实行业/风格归因已通过。需要提供含版本与发布时间的行业/风格模型、历史完整组合/基准权重及同区间因子收益。

现有基准β模块也修复了t值不可计算时的格式异常，并在缺基准日期时停止混合不同期限回归；其普通OLS t值和β乘累计收益仍仅是描述性参考，未升级为稳健显著性或精确多因子归因。软件测试通过不能代替真实模型校准、外部复核和机构准入。
