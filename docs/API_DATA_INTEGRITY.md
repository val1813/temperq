# API取数边界与验收

2026-11-06。用户已有的Tushare兼容接口用于只读历史数据获取。供应方返回与本地缓存不构成官方来源认证、独立券商证据或当时可得时间证明。

生产客户端不再把请求参数、供应方消息写入异常文本；成功响应若回显当前密钥也拒绝进入缓存。只接受整数状态码、唯一字符串列名、显式行列表及等宽标量单元格；空列表仍是合法的无记录答复，缺失items不再伪装为空数据。传输、解码、gzip及JSON异常统一为不包含响应正文的ApiError。

HTTP禁止自动重定向，避免携带凭据的请求被转交其他地址；需在私有配置填写最终接口地址。压缩前后各限制32MB，超限停止，不截断后继续分析。大表应缩小查询或使用已有分页，限额不证明数据完整性。该客户端仍兼容原有HTTP配置；应优先使用供应方支持的HTTPS。

全市场快照保存事件文档并绑定摘要，规则见[公司行动](PAPER_CORPORATE_ACTIONS.md)。不会自动用分红API原始公告生成可记账事件：重复公告、实施状态、覆盖范围、时间与税务口径须先核对。

`scripts/verify_tushare_sample.py`可用私有参数`--endpoint`、`--token-file`、`--out`对固定的一只证券及历史区间运行生产客户端和缓存。输出目录必须全新，仅归档响应表与安全元数据，不归档请求密钥、请求体或供应方错误正文。它不启动账户、不访问未来数据。使用相同的历史区间再次取数不等于新增独立市场样本。

本机HTTP验收覆盖gzip、压缩前后超限、307重定向、无效编码/JSON、畸形表格及密钥回显；全市场更新验收覆盖事件继承、文件损坏、版本追加、无新行情的覆盖扩展、重试和日历修订。外部网络可用性和供应方质量以实际取数结果单独记录。
