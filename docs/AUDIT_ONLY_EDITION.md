# 离线审计版与简化界面

2026-11-06。定位：有回测经验的投资者、策略研究员及团队复核人员。这里的用户定位不等于法规定义的“专业投资者”资格认定，也不代表产品获得机构认证。

## 使用流程

1. 上传同一次回测的 CSV、原策略代码或平台 ZIP，点击“上传并核对”。文件无需改列名或解压。
2. 核对识别出的文件及佣金等关键参数，确认材料来自同一次回测，点击“一键审计”。
3. 查看发现、盈亏归因、证据覆盖和版本对比；完整 HTML 报告、JSON 及逐项 CSV 可下载复核。

| 材料 | 要求 | 影响 |
| --- | --- | --- |
| 原策略代码 | 必填；可上传或粘贴 | 只静态读取，不执行；仅代码可做静态检查 |
| 成交记录 | 财务审计需要 | 聚宽持仓可推算净变动，但不能代替逐笔成交、真实费用及日内路径 |
| 每日持仓及账户汇总 | 推荐 | 决定现金、库存、权益与盈亏能否完整复算 |
| 日志及完整委托 | 选填 | 帮助核查未成交、部分成交及执行偏离 |
| 打分、候选行情、分钟量、涨跌停及上市日期 | 选填 | 解锁相应信号和成交条件检查，缺项逐项标明 |
| 独立券商、因子及风险材料 | 选填 | 独立证据仍须用户提供，不由回测文件派生或冒充 |

选填和高级参数默认折叠。缺少选填材料不阻止其他可实施检查；没有账目、足够样本或所需行情时不生成相应的肯定结论。期初为空仓和无外部资金流仍须明确声明，不能从代码里的初始本金自动认定。

## 与完整工作台的边界

审计版使用独立 `audit_app`，只注册审计、报告、比较、归因、账户方案和独立证据路由。无训练、行情下载、任务 worker、纸面账户自动生命周期。`/data/tushare` 等旧 POST 地址在该应用内不存在；不用隐藏按钮代替服务端边界。

联网连接器、训练模块及训练依赖不进入审计版的活动安装包。证券代码、账户持仓输入和执行规则已提取为共享纯工具；完整工作台继续复用同一实现。审计版不需要行情 token；用户用自己的原平台或标准 CSV 补件。

完整工作台原入口继续保留，默认 `temperq ui` 行为不变；已有数据与账户不迁移。源码开发环境启动审计版：

```powershell
.venv\Scripts\python.exe -m qwb.audit_app --no-browser --port 8889
# 或
temperq ui --edition audit --no-browser --port 8889
```

发行包的 `start.bat` 直接调用随包解释器和 `qwb.audit_app`。`temperq.bat audit ...` 只注册审计命令；完整工作台另行发行。审计程序仍只监听 127.0.0.1，保留本机 Host 与表单 token 检查。

```powershell
python scripts/build_windows_portable.py <新目录> --edition audit --python-home <独立CPython3.11目录>
python scripts/check_audit_portable.py <新目录>/TemperQ-audit-windows-x64.zip <新的迁移目录>
```

`requirements-audit.lock` 使用与完整工作台相同的基础包版本，去掉 LightGBM、BaoStock 等训练项；独立安装核对运行包确实没有训练、行情和调度模块。包内保留源文件哈希、依赖版本、提交号和工作树状态。交付验收从已提交且干净的工作树构建；本地提交与验收不代表已经推送或通过远端CI。

全仓库测试包含完整工作台。可选Torch缺失时用pytest.importorskip跳过；Windows原生Torch DLL加载的126、127、1114、1455错误额外按可选运行时不可用跳过，其他异常仍失败。跳过数和原因必须随测试结果保留，不把跳过写成训练功能验收通过。

## 验证要求

- 阻止旧行情和训练模块导入及外部网络访问后，执行五种样本格式的 CLI 审计和网页导入、确认、审计、HTML 导出。
- 实际验证必填缺项、仅代码静态检查、同次回测确认、摘要过期、CSRF、补件版本及旧报告保留。
- 独立便携解释器迁移验收：核对所有清单文件，在源码目录外用非editable包运行实际 HTTP 流程，旧训练/下载/自动账户地址 GET/POST 均返回404。
- 浏览器验收桌面和手机的上传、折叠、确认、报告与下载。测试材料仅用合成样本；不启动用户账户或任务。

本轮实际数量、截图与包 SHA-256 以交付目录的验收清单为准。这里不把软件测试通过写成真实券商对账、独立盲测或机构准入通过。审计版不包括本轮未开发的云端订阅计费、登录和租户隔离。
